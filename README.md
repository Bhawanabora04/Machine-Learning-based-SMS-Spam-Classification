# 📩 SMS Spam Classification

This project is a **Machine Learning based SMS Spam Classification** system.

The objective of this project is to classify SMS messages into two categories:

- **Spam** – unwanted or promotional messages
- **Ham** – normal/legitimate messages

---

## 📌 Project Overview

In this project, SMS text data is processed and Machine Learning algorithms are used to identify whether a message is Spam or Ham.

The project includes:

- Data loading
- Data cleaning
- Duplicate removal
- Text preprocessing
- Feature extraction using TF-IDF
- Machine Learning model training
- Model evaluation
- Spam/Ham prediction
